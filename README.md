# APF IT Consulting

Modern, high-performance web presence for **APF IT Consulting**—a technology consulting firm specializing in Artificial Intelligence (AI), Data Analytics, SaaS development, and Mobile Applications.

## Overview

- **Design System**: Obsidian Kinetic with iOS 26 Liquid Glass floating navigation
- **Typography**: Sora (headlines) + Geist (body & telemetry)
- **Features**:
  - Live 3D particle simulation background powered by Three.js
  - Liquid Glass floating island navigation header
  - Core capabilities matrix (AI Solutions, Data Analytics, SaaS & Mobile Apps)
  - Representative client case studies with interactive carousel
  - Modern technology stack breakdown
  - 4-step agile engagement lifecycle
  - Interactive advisory consultation modal & client vault authentication drawer
  - Fully responsive, accessible, dark-mode native layout

## Project Structure

```text
├── index.html       # Single-page application entrypoint
├── design.md        # Obsidian Kinetic design tokens & typography specification
├── images/          # Local vector SVGs, transparent monograms & case study assets
└── README.md        # Project documentation
```

## Getting Started

Open `index.html` in any modern web browser or serve with a lightweight local HTTP server:

```bash
# Python
python -m http.server 8000

# Node / npx
npx serve .
```
